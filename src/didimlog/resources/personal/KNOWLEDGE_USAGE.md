# Personal Knowledge 사용 방법

저장소 파일을 만들거나 고치기 전, 명령을 실행하기 전, 작업 절차를 답하기 전에 아래 조회를 먼저 한다. 작업이 짧거나 쉬워 보여도 건너뛰지 않는다. 한 작업에서 한 번 조회하고, 작업 주제나 Git 최상위 디렉터리가 바뀌면 다시 조회한다.

1. 현재 Git 최상위 디렉터리 이름을 확인한다.
2. `~/knowledge/index/_global.md`와 `~/knowledge/index/<project>.md`에서 작업 관련 제목과 `찾을 때` 문구를 text search한다. 두 파일을 처음부터 전부 읽지 않는다.
3. 일치한 항목의 `상세` 파일만 관련도가 높은 순서로 최대 5건 읽는다.
4. 일치하는 항목이 없으면 추가 자료를 읽지 않고 작업을 계속한다.

저장소 파일과 무관한 순수 대화나 개념 설명만 요청받았을 때는 조회하지 않는다.

`lessons/`는 검증된 행동 규칙, `docs/`는 정확한 절차·계획, `book/`은 배경과 사례를 설명하는 해설이다.

적용 조건이 맞는 lesson은 지켜야 할 지침으로 사용한다. 검토 기한이 지났거나 반증·미검증된 내용은 확정 지침으로 사용하지 않는다.
